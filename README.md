# Grow Advisory Group Website

WordPress-ready website package for Grow Advisory Group.

This repository contains the WordPress theme source. The final package includes the static reference build, SEO architecture, legal pages, Projects structure, Insights/blog migration approach and WordPress implementation guide.

## Current homepage positioning

- Family Business
- Growing Businesses - Accounting, tax and advisory that scales with your business.
- Family Offices
- Established Businesses - Financial control, reporting and senior commercial advice.

## Deployment

Production deployment requires explicit approval after WordPress migration, regulatory placeholder completion, URL/301 validation and production QA.
